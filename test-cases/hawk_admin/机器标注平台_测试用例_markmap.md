# Hawk 机器标注平台核心接口测试用例

> **测准声明**：本文件以 `/Users/fish/project/Auto-Test/biaozhu/tc-hawk-admin` 当前工作树实际实现为唯一功能基线；OpenAPI 快照仅作接口目录对照，偏离见附录。代码级证据统一放在文末附录，不写入正文用例。

> **功能简介**：Hawk 是机器标注平台的管理 API，负责项目、阶段、流程和批次的配置、执行及结果查询。本文先覆盖总平台登录后的 P0/P1 核心主链路。
>
> **角色**：Hawk 管理员/开发者 → 创建和维护项目、阶段、流程、批次并执行批次；Hawk 查看者 → 查询授权范围内资源和运行信息，不执行写操作；总平台用户 → 通过统一登录获得访问令牌。

**术语表**

| 术语 | 中文名 | 说明 |
|---|---|---|
| Token | 访问令牌 | 总平台登录成功后放入 `Authorization: Bearer ...` 请求头的凭证 |
| Project | 项目 | 机器标注任务的业务容器 |
| Stage | 阶段 | 流程中的一个处理节点 |
| Flow | 流程 | 按顺序编排多个阶段的处理定义 |
| Batch | 批次 | 使用某个流程处理一组输入素材的执行实例 |
| CID | 圈选集标识 | 以 `CID://` 开头、直接引用已有素材集合的输入路径 |
| Init(0) | 未启动 | 批次创建后的初始状态，也是唯一允许修改输入文件的状态 |
| Running(1) | 处理中 | 批次正在被 Hawk 执行 |
| Stopping(2) | 暂停中 | 批次正在停止 |
| Stopped(3) | 已暂停 | 批次暂停完成 |
| Done(4) | 已完成 | 批次处理完成，等待导出或后续操作 |
| Terminated(5) | 已结束 | 批次被终止 |
| Exported(6) | 已导出 | 批次结果已导出 |

**图例**：P0=失败即阻断核心主链路；P1=常规功能或常见异常；P2=低频边界；`TC-{模块号}-{序号}`=平台内唯一编号，跨子平台由 `meta.platform` 区分；`SMOKE-n`=冒烟序号；本文后端接口用例均为“测试-开发协作执行”。

> **共享前置**：除鉴权模块外，以下用例均已用总平台账号登录并取得有效 Token；写入型用例使用带用例编号的唯一名称，并在执行后删除测试数据。

## 1. 统一认证与请求鉴权

### 1.1 登录主链路

- **TC-01-01 使用 RSA 公钥加密密码并登录总平台** [P0]（SMOKE-1）
  - 前置条件: 已取得 `config/test.local.yaml` 中的账号密码。
  - 操作步骤（请开发执行）: 1. 调用 `GET /api/auth/rsa` 获取公钥 2. 使用该公钥按 RSA PKCS#1 v1.5 加密明文密码 3. 调用 `POST /api/auth/login` 提交账号和密文密码 4. 将返回令牌用于调用 `GET /api/v1/project?page=1&pageSize=1`
  - 预期结果（请开发反馈）: 登录返回有效 Token；Hawk 项目列表请求返回成功，且响应包含业务数据结构。
  - 验证方式: 开发反馈登录响应中的 Token 非空，并核对 Hawk 网关访问日志确认使用该 Token 完成鉴权。

- **TC-01-02 缺少 Token 访问 Hawk 接口** [P1]
  - 操作步骤（请开发执行）: 1. 不带 `Authorization` 请求头调用 `GET /api/v1/project?page=1&pageSize=1`
  - 预期结果（请开发反馈）: 请求被拒绝，HTTP 401，提示缺少身份令牌。
  - 验证方式: 查看 API 响应和网关鉴权日志。

- **TC-01-03 使用无效 Token 访问 Hawk 接口** [P1]
  - 操作步骤（请开发执行）: 1. 使用 `Authorization: Bearer invalid-token-20260902` 调用 `GET /api/v1/project?page=1&pageSize=1`
  - 预期结果（请开发反馈）: 请求被拒绝，HTTP 401，提示身份令牌无效。
  - 验证方式: 查看 API 响应和统一认证服务调用结果。

- **TC-01-04 使用查看者 Token 执行写操作** [P1]
  - 前置条件: 已取得具有 `hawk-viewer` 角色的有效 Token。
  - 操作步骤（请开发执行）: 1. 使用查看者 Token 调用 `POST /api/v1/project`，提交名称 `TC-01-04-viewer-project`、素材类型 `图片`、通知级别 `0`

  - 验证方式: 开发查项目表确认无该名称记录，并反馈权限中间件响应。
