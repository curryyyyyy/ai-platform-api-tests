## 基线

- 上游仓库：`https://gitlab.ituchong.com/ai-dataset/ai-source-admin`
- 分支/commit：`master` / `55040a84d1d711ed4198215bc61be43b93ab1d85`
- 输入材料：上游 `docs/api.md`、`docs/*-api.json`、生成路由和自定义路由
- 关联接口清单：[`资源管理平台_接口清单.md`](./资源管理平台_接口清单.md)

## requirement_model

### goal

接入资源管理平台的 HTTP API，为后续接口契约检查和业务接口自动化提供稳定的 49 操作接口基线；成功标准是接口、认证域、关键输入/输出、异步状态和文档差异均有可追溯来源。

### scope

- 数据管理：圈选 SQL、圈选集查询/更新、集合运算、原始图片下载、CSV 导入、复合数据预览。
- 文件系统：节点创建、查询、搜索、移动、删除和批量查询。
- Schema 管理：Schema 与字段 CRUD、批量更新、TOS 同步、版本查询和回滚。
- 分享链接：创建、查询、列表和终止；另有公开分享读取入口。
- 审计日志：按操作类型、操作用户、时间范围和分页查询。
- 非目标：本轮不生成 pytest 用例、不接入线上环境、不猜测缺失错误码/边界、不把 HBase/DevTools 专用入口并入 49 个主业务操作。

### roles

- 已登录用户：通过登录 Token 访问 `/api/v1` 下的业务接口；可执行的资源范围和 OWNER/非 OWNER 权限未在材料中完整定义。
- 分享访问者：持有分享 Token，访问公开分享详情、集合标签和分页数据；不依赖登录 Token。
- HBase/DevTools 调用方：使用专用 `HBaseAuth()` 访问 HBase 查询和数据集下载工具。
- 后台异步任务：执行圈选、集合运算、CSV 导入和原始下载；任务状态通过查询接口暴露。

### inputs

- 请求头：主业务接口声明 `Authorization: <token>`；公开分享使用 URL 中的分享 Token。
- 路径参数：集合、任务、节点、Schema、字段、版本和分享链接 ID。
- 查询参数：筛选条件、分页、时间范围、节点搜索范围和字段版本场景。
- JSON 请求体：条件组、SQL、集合 ID 列表、节点/Schema/字段变更、分享链接配置、CSV/TOS 路径等。
- 外部依赖输入：HBase 展示列、TOS 文件路径、Hive/LanceDB 数据源、RPC 数据服务；可用测试依赖未确认。

### outputs

- 通用响应字段：`code`、`msg`，但数据管理文档同时使用 `base` 和扁平业务字段，具体以各 OpenAPI JSON/实际响应为准。
- 资源数据：Collection、Node、Schema、SchemaField、ShareLink、AuditLog 及分页总数。
- 异步任务句柄和状态：原始下载 `task_id`、圈选/集合运算 `collection_id`、CSV 导入状态。
- 外部资源：TOS 预签名上传/下载地址、下载错误明细地址、复合数据预览 URL。

### states

- 原始下载：`PENDING -> RUNNING -> SUCCESS`；全部源图片失败时 `RUNNING -> FAILED`。部分失败仍可 `SUCCESS`，并包含失败明细。证据：E1，`docs/api.md` 第 33-98 行。
- 圈选/集合运算任务：`PENDING -> RUNNING -> SUCCESS/FAILED/CANCELED`。证据：E1，`docs/api.md` 第 180-263 行；E1，`docs/data-manage-api.json` 的 `JobStatus`。
- CSV 导入：上传地址 -> CSV 检查 -> 异步导入 -> 状态查询 -> 成功或失败明细。具体状态集合和超时未定义。证据：E2，`biz/router/ai/data/manage/datamanage/data_manage.go`；E1，`docs/data-manage-api.json`。
- 分享链接：`ACTIVE -> TERMINATED`；文档另定义 `EXPIRED`，过期触发方式和时间单位未定义。证据：E1，`docs/api.md` 第 829-889 行；E1，`docs/share-api.json`。
- Schema 字段版本：字段变更产生版本 -> 查询快照 -> 回滚恢复快照字段。证据：E1，`docs/api.md` 第 774-829 行；E2，`server/ai/data/manage/scheme/schema_field_version_service.go`。

### rules

- 所有生成的 `/api/v1` 业务路由通过 `middleware.Auth()` 进行登录认证。证据：E2，`biz/router/ai/data/manage/{datamanage,filesystem,scheme,share,audit}/middleware.go` 的 `_v1Mw`。
- 原始下载只支持节点类型 `2`（图片），请求 rowkey 最多 1000 个，服务按首次出现顺序去重。证据：E1，`docs/api.md` 第 33-54 行；E1，`docs/data-manage-api.json` 的 `CreateOriginalDownloadRequest`。
- 圈选条件支持嵌套条件组；逻辑操作符 `1=AND, 2=OR`。主文档列出操作符 1-15，结构化契约扩展到 31，范围未统一。证据：E1，`docs/api.md` 第 101-178 行；E1，`docs/data-manage-api.json` 的 `Operator`。
- 展示列更新按传入顺序生效；包含展示列字段时，圈选集数据查询必须同时传入原始 `rowkey`。证据：E1，`docs/api.md` 第 337-421 行。
- 集合类型更新会同步关联文件节点类型，并记录审计日志。证据：E1，`docs/api.md` 第 486-531 行。
- 文件节点类型至少包含文件夹、图片、视频、音频、通用数据、3D 和其他；主文档与结构化契约的枚举需进一步统一。证据：E1，`docs/api.md` 第 423-455 行；E1，`docs/data-manage-api.json`。
- Schema 字段支持 `string / int / float / array / enum`，`enum` 可带选项；展示格式包含 `text / date / number / tag / tos_img_url / image`。证据：E1，`docs/api.md` 第 714-772 行。
- 公开分享集合数据接口每次调用会增加浏览次数，且分享 Token 与登录 Token 是两套认证。证据：E2，`router.go`；E1，`docs/share-api.json`。

### exceptions

- 未携带、无效或过期登录 Token 的行为、HTTP 状态码和业务码未定义。
- 资源不存在、无权访问、重复名称、非法状态转换和跨用户资源访问的响应结构未定义。
- 异步任务部分失败、全部失败、取消和重复提交的幂等规则只部分描述，缺少统一错误码和时限。
- `composite/preview` 的路由实现未挂登录中间件，但结构化 OpenAPI 使用全局 Bearer 声明，认证预期冲突。
- 主文档与结构化契约对分享创建必填字段、审计操作类型和条件操作符范围存在差异。
- 分页、名称/字段/SQL/文件名长度、时间戳单位边界和请求体大小未定义。

### dependencies

- 认证服务：`middleware.Auth()` 依赖登录 Token 校验服务；具体登录入口不在本仓库 `docs/api.md` 中。
- 数据服务：HBase、Hive/LanceDB 和 `ai_source_data` RPC；决定圈选、标签、数据分页和统计结果。
- 对象存储：TOS，用于 CSV 预签名上传、字段同步、导出下载和原始图片 ZIP。
- 文件/资源关系：文件节点与 Collection 通过 `file_node_id`/`resource_id` 关联。
- 异步执行器：圈选、集合运算、CSV 导入、原始下载任务需要轮询和最终一致性判定。
- 审计日志：Collection、文件节点、分享和集合运算等写操作产生审计记录，但覆盖范围未完整声明。
